AquaTime 🌊

AquaTime is an Android relationship timer widget app with a transparent aqua-glass aesthetic.

Features

- Together Time widget
- Time Apart widget
- Customizable transparent widget appearance
- Aqua, rain, ocean, and blue themes
- Offline operation
- Local settings storage

Platform

- Native Android
- Kotlin
- Jetpack Compose
- Android AppWidget

Build

The Android APK will be built using GitHub Actions.
